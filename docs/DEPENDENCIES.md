# Third-party dependencies of the profile page

Measured from `README.md`: **9 hosts, 23 URLs** — 3 serve images, 6 are link
destinations. `python3 -c` host count is reproducible with the snippet at the
bottom. Anything listed here that dies changes what a reader sees; nothing else
does.

## Image hosts — the page looks wrong when these fail

| Host | Serves | If it is down | Mitigation in the README |
|---|---|---|---|
| `raw.githubusercontent.com` | `header.svg` (1 URL), `city-dark.svg`, `city-light.svg` (2 URLs) | The banner and the contribution city are missing | Both are produced in this repo (`assets/header.svg` is hand-written static SVG, the city is generated by `.github/city.py`), so the fix is a same-branch path change, not a dependency hunt. The city's numbers also exist in the GitHub contribution graph. |
| `img.shields.io` | 4 badges (Portfolio, LinkedIn, Resume, Email) | The four links lose their coloured badges, so nothing clickable remains in their place | Each badge's `alt` names its destination (m1.2.1); the destinations are plain URLs that also appear in the resume and here in git history. |
| `skillicons.dev` | The 14-icon stack strip (1 URL) | Icons vanish, leaving a gap | The stack is written out as text in the same section (`**Stack:** TypeScript · … · Three.js`), and the strip is decorative (`alt=""`). |

## Rules

1. A new external host is a new dependency: add it to this table in the same commit.
2. `scripts/check_page.py` fails when `README.md` points at a host this file does not name.
3. Image URLs keep every visual parameter explicit (`theme`, `perline`, `height`,
   `fontSize`, `style`, `logo`, colours), so an upstream default change cannot
   silently restyle the page.
4. A host whose terms forbid hotlinking gets replaced, not documented.
5. The banner is **self-hosted** (`assets/header.svg`, 1,001 B, no third-party
   renderer): its title and tagline are real text in the README, so the banner
   only has to be a gradient. It replaced `capsule-render.vercel.app` in m2.3.3.

## Pinned parameters

Every appearance-affecting parameter is spelled out in the URL, so an upstream
default change cannot restyle the page silently:

| Host | Pinned |
|---|---|
| `img.shields.io` | `style=flat-square` × 4, `logo`, `logoColor=white`, `labelColor=555` |
| `skillicons.dev` | `perline=14`, `theme=light` (the theme default is what would otherwise drift) |
| `raw.githubusercontent.com` | exact branch (`master`) and file name |

## Counting the hosts

```bash
python3 -c "import re;from urllib.parse import urlparse;t=open('README.md').read();u=re.findall(r'(?:href|src)=\"(https?://[^\"]+)\"',t)+re.findall(r'srcset=\"(https?://[^\"]+)\"',t)+re.findall(r'\]\((https?://[^)]+)\)',t);print(len(set(urlparse(x).netloc for x in u)),'hosts',len(u),'urls')"
```
